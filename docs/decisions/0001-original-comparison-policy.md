# ADR 0001: 原作との比較に基づく仕様判断

日付: 2026-10-06
状態: 採用（ユーザーから指定された判断手順）

## 背景

原作1.52の回収ソースには、移植漏れだけでなく原作自身の誤記や不自然な状態変更も見つかる。現状の挙動をテストで記録した後、差分をすべて原作へ戻すと、WPF版で既に補正した挙動も失われる。

## 決定

判断には次の三種類の根拠を使い、混同せず記録する。

1. **観測事実**: 原作ソースと現在の実装・テストで確認した処理。静的解析と原作実行による確認を区別する。
2. **設計仮説**: Astraが提案する「ゲームとしてどうあるべきか」。理由・代替案・確信度を添え、原作作者の意図とは断定しない。
3. **採用判断**: 互換性、ゲーム内の整合性、既存の修正意図、ユーザーの選択を踏まえた方針。

解析結果と採用判断はそれぞれAstraでレビューする。明確な移植漏れを直し、原作の疑わしい処理や複数の妥当な仕様がある項目は現状を維持して質問候補に残す。仮説が説得的でも、それだけで未承認のゲーム仕様を変更しない。

実装には採用した仕様を確認するテストを追加する。変更前の挙動はGit履歴で保全し、採用した変更に関係する期待値だけを更新する。コードコメントは日本語を基本とする。

## 影響

解析は [原作比較](../original-analysis.md)、未決事項は [判断待ち一覧](../pending-decisions.md) に集約する。個別の採用判断は別のADRに、変更理由・却下した代替案・挙動への影響・検証結果を記録する。調査範囲外の一致や原作実行での一致を保証するものではない。
