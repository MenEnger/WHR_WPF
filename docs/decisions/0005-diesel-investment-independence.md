# ADR 0005: 高度ディーゼル改良はディーゼル投資で判定する

日付: 2026-10-06
状態: 採用（ユーザー判断、既存実装を維持）

原作main.as:519の高度改良はディーゼル開発値360以上で電車投資gjw.2を参照する。WPFはディーゼル累計投資と括弧を補った閾値を使う。

電気式・シリーズハイブリッドの世界観から電気技術を条件にする案を検討したが、ユーザーは「電化に依存しない方向、ディーゼルだけで判定」を選択した。高度改良は既存WPFのディーゼル投資のみの判定を維持する。

360以降の+10はメッセージが作成費低減でも、開発値が車両価格と作成可能速度を兼ねるため速度上限にも作用する。通常+5条件も360以降に実行され、両方通れば同週+15になり得る。原作の作者が意図した依存関係とは断定しない。

今回の決定はF10の高度改良判定が対象。既存CanDieselDevelopの投資UIの初期前提（電気技術80以上）は通常開発の別条件であり変更しない。これを除去するか、モデルの開発判定にも統一して適用するかは別途判断する。

開発値400の高度改良閾値ぴったり/1超過、電車投資のみでは開発値360が進まないケースをテストする。現状の通常+5と価格計算の同居を変えるリファクタリングは含めない。

検証結果: 全159件成功。回収6モード48週後の人口照合も全60都市一致。Astraが実装・状態変更テスト・採用判断との整合をレビューし、追加P1/P2指摘なし。0購入の債務時失敗はレビューで検出し、早期returnとテストで解消した。UI実画面の操作は未確認で、ViewModelとXAMLビルドによる検証。
