# ADR 0007：実行中の期限による終了判定

状態: 採用。2026-10-06。Issue #7、PR #32。

## 背景

モード開始時には `SelectedMode.MYear` から `GameInfo.MYear` へ期限がコピーされる。目標達成後は目標が解除され、実行中の `GameInfo.MYear` が `BasicYear + 420` に延長される。しかし終了判定は初期設定の `SelectedMode.MYear` を参照していたため、1880年モードでは達成後も1921年に旧期限で終了していた。

## 判断と理由

終了判定は実行中の `GameInfo.MYear` を参照する。正の期限を越えた場合に終了し、0以下は期限なしとする。初期設定と実行中の期限を分け、達成後の期限延長を終了判定にも反映する。

## 検討した代替案

- 初期設定の期限も書き換える：実行中の状態だけで足りる修正に、初期設定の変更を追加するため採用しない。
- 目標解除後は期限判定を省略する：フリーモードに設定されている延長期限まで無効になるため採用しない。

## 影響と検証

達成後は旧期限を越えて継続できる。未達成時の期限切れ、期限なし、日付更新後の期限判定を達成より優先する順序、フリーモードの延長上限は維持する。1880年モードでは2300年を越えると引き続き終了する。

同じ目標・期限の小シナリオで修正前に誤終了を再現した。回帰テスト7ケースと全169件が修正後に成功し、実装とテスト網羅をAstraがレビュー済み。実画面での再プレイは未実施。

期限最終週の優先順位を変更するか、目標説明と検査対象の整合、フリーモード終了文言は [判断待ち一覧](../pending-decisions.md) に残す。
