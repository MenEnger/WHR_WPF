# ADR 0004: 数量の負数を状態変更前に拒否する

日付: 2026-10-06
状態: 採用（ユーザー判断）

原作はUIで購入数を制限するが、モデル相当の計算は負数を防がない。以前保留した理由は互換性調査だけで入力契約を決めないためであり、負数を正しい数量として扱う必要があるためではない。

ユーザーの判断に従い、購入・供出・返却・売却の数量と割当運行本数は負数を状態変更前に拒否する。購入と返却、割当にガードを追加する。供出と売却は既存のUseによる拒否を維持する。数量0は無操作を認め、運行本数0は従来の停止設定を認める。

収支の増減やSpendMoney/AddMoneyの符号付き金額は数量コマンドと異なるため、その負数を一律拒否する変更は行わない。不足数の計算や割当失敗時の原子性は別の未決事項とする。

両編成実装の負数/0、資金・余剰編成数保持、直接/系統の負本数によるダイヤ・旧割当保持をテストする。

検証結果: 全159件成功。回収6モード48週後の人口照合も全60都市一致。Astraが実装・状態変更テスト・採用判断との整合をレビューし、追加P1/P2指摘なし。0購入の債務時失敗はレビューで検出し、早期returnとテストで解消した。UI実画面の操作は未確認で、ViewModelとXAMLビルドによる検証。
